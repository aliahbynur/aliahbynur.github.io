# Fabulinus Document Generator

A lightweight browser-based document generator for the Drama Club of the Department of English, Aliah University, Park Circus Campus.

## Current features

- Notice generator
- Agenda generator with add/remove items
- Minutes of Meeting generator
- Attendance Sheet generator with add/remove participants
- Live A4 document preview
- Print / Save as PDF using the browser print dialog
- Responsive editor and preview layout

No backend or external dependency is required.
